# New Athena Unicode

The `new-athena-unicode*.woff` files are the Regular and Bold webfont files
from New Athena Unicode version 5.008, obtained from the official GreekKeys
distribution maintained by the American Philological Association / Society for
Classical Studies:

https://apagreekkeys.org/NAUdownload.html

They are bundled only for the calendar-album date text and are not used as an
application-wide UI font. The accompanying `OFL-1.1.txt` contains the license
text supplied by the official distribution.

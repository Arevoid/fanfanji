- `npm ci --ignore-scripts --dry-run` 通过。
- TypeScript lint 通过。

## 明确不在本轮实施的内容

- 不改变当前 API 地址支持范围、认证方式或请求路径。
- 不新增 API 限流、域名白名单、内网地址拦截或强制认证。
- 不改变备份 API Key 的现有明文/脱敏/加密行为，不引入密码备份流程。
- 不自动删除旧数据、迁移副本、失败快照、任务记录或孤儿资源；清理必须由用户确认。

## 收尾条件

仓库内目标可在以下条件同时满足后视为完成：代码门禁持续全绿、交接文档与本清单一致、API/备份暂缓边界未被改动。真实设备、staging、弱网和跨部署项目必须在对应环境完成后，才能把本清单中的“待外部验收”改为完成。

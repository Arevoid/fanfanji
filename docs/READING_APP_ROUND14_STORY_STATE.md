# 阅读应用 Round 14：单人穿书结构化状态

本轮开始第四阶段“单人穿书”，先锁定状态协议，不接入模型正文生成。

## 结构化对象

- `ReadingStoryState`：故事身份、穿法、长度、章节进度、地点、时间、角色目标、情报、任务和关系状态。
- `ReadingStoryTurn`：每回合正文、对话、选项、状态变化、情报、任务/关系变化和章节结束标记。
- `ReadingStorySave`：回合引用和完整状态快照。

每条记录绑定 `userIdentityId + storyId`，单独存放在 `phone_reading_story_store_v1`，不会进入阅读私人进度、共读房间或主记忆。

## 回合提交

模型返回必须先经过 `validateReadingStoryTurnResult`。程序保存回合后再更新故事状态，正文中的地点、章节和情报不能只存在于自然语言里。当前实现支持选择与自由输入的 `userAction`、自动推进章节、短/中/长三种目标长度，以及状态快照存档/读档。

下一轮接入故事 Prompt 时，必须让模型只返回此协议结构，并在事务失败时保留旧状态。

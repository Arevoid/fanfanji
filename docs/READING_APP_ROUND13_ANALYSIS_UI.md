# 阅读应用 Round 13：小说分析 UI

## 书籍详情页

书籍详情现在包含“小说分析”面板：展示任务状态、章节完成数、百分比、失败原因和“从检查点重试”。没有运行任务时可以创建当前书籍版本的章节分析任务；输入版本使用书籍内容哈希，版本变化不会复用旧任务。

面板只展示任务元数据，不在 UI 中读取或上传整本正文。真正的模型调用仍需经过 Round 12 的章节 Prompt 和结构化结果协议。

## Book Bible

详情页增加 Book Bible 卡片：展示 premise、世界规则、版本和来源状态。用户可手动编辑 premise 与世界规则，保存后标记 `isUserEdited`，并保留人物、地点、势力、故事线和时间线索引。Book Bible 仍严格绑定 `userIdentityId + bookId`，不会进入共读房间或主记忆。

## 验收

新增 UI 静态测试覆盖分析入口、进度、失败重试、Book Bible 编辑保存和仓储作用域；完整检查通过后才允许进入下一阶段穿书设计。

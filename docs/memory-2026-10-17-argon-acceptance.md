## 冻结对照

原v1六例及扩展v2五例采用同一模型配置，分别先运行HEAD Git tree基线，再运行当前代码。扩展五例完整通过。原六例首次出现E03状态失败，保留 `memory-frozen-original-argon-20261017.json`，修复后完整重跑通过，见 `memory-frozen-original-argon-fixed-20261017.json`。扩展见 `memory-frozen-extended-argon-20261017.json`。修复影响的E04/E05另作当前代码复测，两项通过，见 `memory-frozen-postfix-facts-argon-20261017.json`。

E03暴露的是未绑定身份的旧复合记录引用：已独立复核的精确自身引用不能建立首次身份，随后宽泛的宠物构成更新替代整条记录。现在仅对确切目标、同范围、已复核的自身引用允许首次身份绑定；另一个无身份记录的引用和JSON伪造不被授权。旧身份改变后，另一条绑定旧版本的修订授权失效，保持待核实。批次先处理可验证的不变事实身份，不让模型输出顺序决定覆盖结果。专项 `memoryLegacySelfReferenceAcceptance.test.ts` 包含正常/反向顺序和伪造/跨目标负例。

遇到旧复合资料中的其他含义无法可靠绑定时，仍保留待核实记录，不自动升级为确定事实。这是原方案规定的不确定性处理，不将疑似冲突强行裁决。

自动回复指标中的 `reply` 是目标词命中，不等于语言学正确率。例如旧版E01既说旧名字又提及新名字也会命中该词，但其修订状态失败，且人工阅读明确为答错；不能把该词命中记为旧版回答正确。对照材料保留原回复及分项状态，不用汇总百分比遮盖这种差别。

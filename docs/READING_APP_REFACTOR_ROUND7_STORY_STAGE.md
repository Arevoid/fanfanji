# 阅读应用布局改版：第 7 轮（统一文游正文舞台）

## 本轮目标

单人穿书、AI 好友共同穿书和自建世界统一使用同一个文游正文舞台，页面结构贴近移动端文字冒险：正文是主页面，选项与自由输入固定在底部，状态与角色信息按需展开。

## 页面结构

- 顶部显示故事名称、同行者或当前角色、章节进度条。
- 正文区域连续滚动，叙述、对话、用户视角和 AI 好友视角保持清晰层次。
- 右侧提供“状态、角色、情报、存档”快捷按钮，不长期占用正文宽度。
- 底部行动区固定，并兼容安全区；选项可展开或收起。
- 点击选项只填入行动输入框，仍由用户确认提交。
- 用户也可以完全忽略系统选项，自由输入行动。

## 统一组件

`ReadingStoryPlayShell` 只负责表现和交互框架，不持久化故事数据。单人故事与共同故事仍使用各自的仓储和生成协议，避免为了统一 UI 而合并记忆域。

## 移动端规则

- 正文底部预留行动区高度，最后一个回合不会被输入框遮挡。
- 选项列表限制最大高度，可在底部区域内部滚动。
- 输入时不会因为每次键盘敲击自动滚回正文底部。
- 档案面板使用底部抽屉，关闭后回到原正文位置。

## 执行边界

保留已验证的存储、权限、来源保护和向量接口。新增正式语义比较、稳定实体/属性身份、事件引用、加权认识修订、连续生活状态，以及明确导入的离线读取帧；不以关键词表或 Prompt 指令代替状态机制。没有复制参考项目的代码、提示词或素材。

## 关键修复

- 提取器在同一正式请求中比较有权限的既有事实；运行时验证新旧原文，保留修改链，不擅自改变关系身份。
- 事件支持相同活动的不同场次及明确引用，历史日期查询能跟踪改期后的版本。
- 语义价值评估限制普通闲聊进入记忆；重点候选和人工核心分开，过往普通内容归档保留。
- 各类记忆统一参与可恢复的向量覆盖及预算控制；公开/历史/近期去重等不同读取条件不能共用不兼容的并发结果。
- 认识按语义主题及独立来源证据逐渐改变；单次反例待观察，旧观点和依据保留。
- 角色生活保存目标、步骤、精力、压力、习惯和烦恼；NPC只知道明确共同经历；可暂停，关闭应用期间不编造已发生事实。
- 重新生成按原时点读取事实、认识和行为维度；未明确导入的离线分支不读线上记忆，多人剧情不合并私有资料。
- 群聊逐角色召回并隔离判断，只让封闭表达方式进入共享请求；动态和论坛保持公开资料边界。
- 迁移基础搬运、语义拆分、跨来源关联和索引覆盖分别记录状态；单句资料不重复拆分，失败不前移游标，部分覆盖保留原卡。
- 删除旧事实版本不会误删不同的新值；删除某个整理分句不会让原卡重新泄出该分句，其他分句保留。

所有阶段均以专项测试验收；真实模型、真实 Embedding、隔离组件 UI、真实备份内存副本回放及构建检查单独列证，不相互替代。最终报告列明有限验收范围及产品规则。

## 不得被实现便利性覆盖的规则

- 六类入口：共同经历、未来计划、对我的认知、TA的变化、TA的生活、线下经历；同一实体多入口引用，不复制事实。
- 短期上下文不展示；摘要只作背景，不与原子内容重复铺陈。
- 不再因缺少价值评估而直接授予正式记忆资格；计划/偏好无自动保留捷径。无法判断保留原文与需核实状态，禁止以关键词黑名单替代判断。
- 人设/世界书纯重复不新增；相关真实新经历保留；只核对有权使用的资料，不让模型输出授予权限。
- 通话结束提取实际已保存文字/可靠转写，不用时长代替内容；没有内容不编造。来源版本与重复结束幂等。
- 续写退出自动增量同步线上；IF/导演仍隔离。无新增零提取，新增只处理新来源；编辑、删除、重生成重新评估，崩溃恢复；多人知情分别限制。
- 日记可查看写作记录与正文，但默认不提取、不向量化、不召回、不作为成长独立证据；明确分享仍按分享快照权限使用。
- 私聊召回最高300条，保留既有有效设置；取消4800字符/3000 Token额外裁剪，不用隐藏上限替代；权限、时间、有效性与相关性继续过滤。
- 简洁/细腻仅影响展示，不改变提取事实、价值、分类与可信度；切换不触发付费重写。
- 已迁移用户不能跳过本次质量整理；原文保留与语义整理完成分开；失败不可推进游标；未知归属不自动召回。

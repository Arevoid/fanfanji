# 阅读应用重构第 3 轮：书籍操作协议

## 封面手势

- 短按封面直接进入阅读器，并在进入前补齐章节解析；不再经过书籍详情页。
- 长按 520ms 打开书籍操作面板；移动超过 10px 会取消，避免用户滚动书架时误触。
- 桌面端右键与长按等价。
- 长按成功后会抑制紧随其后的 click，不会同时进入阅读器。

## 操作面板

操作面板固定提供四项：编辑、书籍封面、共读、穿书。

- 编辑复用既有书籍详情编辑区，不新建第二套资料模型。
- 封面只接受本地图片 Data URL，限制 4MB；更新严格按 `userIdentityId + bookId` 定位。
- 共读进入 AI 好友选择弹窗，创建后仍使用完整关系作用域。
- 穿书进入第 4 轮的统一向导。

归档书籍仍能长按管理，但短按不会直接阅读，需要先移回书架。

## 兼容性

封面继续写入既有 `ReadingBook.coverUrl`，仓储版本不提升。资料编辑继续调用既有 `updateReadingBookDetails`。操作面板本身不持久化任何状态。

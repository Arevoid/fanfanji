# 阅读应用 Round 15：单人穿书主页面

本轮把结构化穿书状态接入阅读应用 UI。

## 页面结构

- 书籍详情增加“穿书：进入这本小说的故事宇宙”入口。
- 穿书首页选择短篇（约 3 章）、中篇（约 8 章）或长篇（约 20 章），并保留已有故事列表。
- 故事主页面以正文为主，回合正文和对话按时间顺序展示。
- 下一步选项以按钮展示，自由输入框允许暂存用户行动；当前版本不会替用户自动提交重大决定。
- 档案面板显示角色名、身份、目标和穿法。
- 情报面板显示已发现情报和任务。
- 存档面板支持手动存档和读档。

## 接入边界

本轮 UI 只读写 `ReadingStoryState/ReadingStoryTurn/ReadingStorySave`，不读取现实聊天 Memory、共读房间或主记忆。模型回合尚未接入；接入时必须把返回值交给 `validateReadingStoryTurnResult`，再通过 `commitReadingStoryTurn` 保存。

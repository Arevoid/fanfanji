# 阅读应用重构第 2 轮：底部导航与封面书架

## 本轮交付

- 默认打开“书架”，底部固定展示“书架 / 共读 / 世界”三个入口；
- 书架使用三列封面网格，支持全部、阅读中、未读、已读完、归档筛选；
- 支持按书名、作者或原文件名搜索，并按最近更新、书名、进度排序；
- 上传封面时直接展示原封面，没有封面时根据书名生成稳定的本地渐变封面；
- 共读栏目展示普通共读和共同穿书，保留关系隔离；
- 世界栏目展示单人故事与共同故事，两处出现的共同故事仍引用同一存档。

## 当前操作边界

封面短按暂时进入既有书籍详情。长按操作面板、封面上传、从卡片直接开始共读/穿书属于第 3 轮。世界新建向导属于后续轮次，本轮只提供现有世界的统一入口和空状态说明。

导入仍仅支持 TXT/Markdown，正文默认只保存在本地。分析小说前的 API 文本发送提示沿用已有分析流程。

# 数据影响与回滚

## 数据影响

第一批新增的唯一持久化数据是有限长度的 AI 请求元数据账本。它不改写消息、
角色、关系、记忆、世界书、角色手机、IndexedDB schema 或已有 localStorage
业务键。账本写入不可用时业务照常运行。

## 回滚

每个提交单一目的，可按提交顺序反向回滚。回滚代码不会删除既有用户数据；若
要清理账本，应通过后续明确的数据管理入口，不能在本批或部署脚本中清空
localStorage/IndexedDB。

## 风险

- 账本增加少量 localStorage 写入，配额不足时会降级为不持久化；
- 浏览器刷新可能丢失未持久化的内存诊断，但不影响聊天；
- Provider usage 缺失时只能保留估算值；
- 代理与浏览器回退仍按旧策略运行，账本不会“修复”或改变它。
